# 第 10 章 ReAct 工具环：白名单 / 步级观测 / 重复收手

> 状态：初稿 v0.1 · 所属：第三部 Agent 化 · 前置：第 8 章

## 10.1 失败先行：自主循环的三种死法

让小模型在循环里自主决定「检索什么、何时收手」，实测三种死法
（每种都有白盒回放测试钉死）：

1. **复读机**：同一调用原样重复 6 步直到烧满预算（实测）；
2. **幻觉参数**：问「半年度」传参 FY——错误参数覆盖后年报块洪水；
3. **不收手**：证据明明够了，继续换角度检索烧预算。

结论：**自主性不是给模型自由，是给模型装护栏。**

## 10.2 工具白名单：封闭世界契约的 Agent 面

```python
# tally/graph.py（节选）
AGENT_TOOLS = [_SEARCH_TOOL, _METRICS_TOOL, _DERIVE_TOOL]   # 就这三个

def _run_tool(name: str, a: dict) -> str:
    if name == "search":        return run_search(a)
    if name == "metrics_table": return run_metrics_table(a)
    if name == "derive":        return run_derive(a)
    return "[]"      # 注册表白名单外：封闭世界契约第 2 条
```

三个工具全是**内部动作**（检索/取表/算术），永无浏览器和外部 API。
白名单外的调用返回空观测——模型看得见「这条路不存在」，但走不出去。

`derive` 值得单独一提（单季差分算子）：

```python
# run_derive：Q2=H1−Q1、Q4=FY−Q3，原币精度；操作数行不可解析时返回
# error 对象（模型可见的保守失败），绝不打印错数。结果登记进
# derived_ops——verify 出口按「操作数必须真在场于证据池」重算 ±0.01
```

**禁止模型心算**——封闭世界里，算术也是事实。模型算出 Q2 净利，
出口处代码重算一遍，操作数（H1、Q1 的原文数值）必须真的在证据池
里——差分值才允许 pass。这是「LLM 组织语言、代码拥有事实」在
算术上的落点。

## 10.3 护栏四件套

```python
# tally/graph.py: agent_research（节选）
seen: dict[str, str] = {}   # 幂等缓存：小模型会把同一调用原样重复 6 步（实测）
...
if key in seen:             # 重复调用：回缓存结果并提示换角度
    msgs.append({"role": "tool",
                 "content": seen[key] + "（重复检索：结果同上。请换检索角度或停止调用工具。）"})
    step.update(gate="dup"); continue
...
if not fresh and pool:      # 整批全是重复 = 模型没有新问题要问
    stopped = "重复收手"
    break
```

1. **幂等缓存 + dup 标记**：重复调用不烧检索、不进证据池，还给模型
   一句「换角度」提示；
2. **整批重复即收手**：比等步数封顶早止损；
3. **步数硬上限** `MAX_AGENT_STEPS = 6`；
4. **理解先验覆盖工具参数**：understand 抽到的期间/公司是「模型对
   原问题的结构化决定」，工具参数只是检索战术——参数幻觉被先验
   拦下（「半年度幻觉成 FY」的死法 2 由此封堵）。

## 10.4 步级观测：waste_rate 是 eₖ 的代理

每一步记录四元组 `{thought, action, obs(条数+首doc), gate(new/dup/empty)}`
+ 耗时，进 state["agent_steps"]——`-v` 逐行打印，`--json` 可重放。
eval 聚合出 **waste_rate = (dup+empty)/calls**，它是可靠性公理里
eₖ（步错率）的可测代理（第 13 章把公理讲全）。

观测先行的意义：没有这四个字段，「小模型在循环里表现如何」只能
靠感觉争论；有了它，「重复率 30%」是一个可以盯着的数字。

## 10.5 诚实边界：远端通道没有 ReAct

`chat_with_tools` 目前**仅本地 Ollama 通道实现**（原生 tools API，
qwen3.5:0.8b 实测可用）；远端 API key 通道显式抛
`NotImplementedError` → agent 环兜底固定管线（trace 标记
`agent:fallback`，答案侧无损——同一 verify 闸门出口，但步级观测
不参与）。这是 v0.7 实测记录在案的通道能力差异（DESIGN-v0.7 §8），
教程不装作它不存在——**接远端 function calling 正是留给读者的
v1.1 挑战题**（开放问题：各家的 tools 协议差异比想象大）。
