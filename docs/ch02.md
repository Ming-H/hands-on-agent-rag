## 本章目标

## 知识点地图

## Tally 代码锚点

```
tally/ingest.py: parse_filename / read_pdf / strip_boilerplate / ingest_file（0 块闸门）· tally/source.py: _fingerprint / scan / diff
```

## 五段式内容大纲

1. 失败先行：日期开头的文件名曾产出垃圾 doc-id 污染检索（P0.5 实测库内留过一具）
2. 决策：元数据只从文件名解析、绝不靠模型猜——为什么确定性元数据是封闭世界的前提
3. 页眉剥离：频率统计 + 空白归一化（P2 事故：一行空格打败逐字比对）
4. 空文档闸门：扫描版 0 块「成功入库」的静默失败与修复
5. 增量摄取：three-way diff、多根共存、指纹=内容哈希的演进
