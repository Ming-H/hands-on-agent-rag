## 13.1 知识：评测三代与它们各自的边界

| 代 | 方法 | 代表 | 能力 | 边界 |
|---|---|---|---|---|
| 人工/规则 | 关键词、精确匹配 | 传统 IR 的 P/R | 零成本、可解释、可 diff | 覆盖窄；词面判定要防子串假命中 |
| 无参考评估 | 生成/检索/忠实分项 | [RAGAS](https://docs.ragas.io)、[TruLens](https://www.trulens.org) | 无需人工真值、可大规模跑 | **裁判模型自带方差**；领域性错误看不出 |
| 领域真值集 | 人工核对答案 + CI 门槛 | 业务 golden set | 唯一能抓领域错误的尺子 | 贵（人工对库核对）；要懂统计 |

**无参考评估（reference-free）的机制**：RAGAS 的 faithfulness 把
答案拆成 claims 逐条判蕴含（NLI/LLM 裁判）、context
precision/recall 量检索噪声、answer relevancy 反向生成问题算
相似度；TruLens 用反馈函数族做同类事。两条边界要说透：裁判
模型有方差（同答案两次打分不同——进 CI 会抖）；语义级判定看不出
**领域性错误**——「问扣非答归母」在通用 faithfulness 下可能满分
（两个数都在上下文里，蕴含判定通过）。**领域真值集是补充不了的
替代品**。

业界方法论代表是 Hamel Husain（[*Your AI Product Needs
Evals*](https://hamel.dev)）：**领域专属评测集 + 错误分析驱动
迭代**，比通用基准重要——用户不问 MMLU，问你领域的问题。配套
纪律是 **eval 驱动开发**：每个设计决策先有失败样本再写修复
（本书案例的 D 编号大多伴着一道 eval 题）——没有失败样本的优化
是盲调。

**评测统计学一句级**（值得展开成半级）：20 题的评测集上，一题
之差 = 5 个百分点。二项分布的置信区间在 n=20、p=0.9 时约 ±13
个点（正态近似）——**「A 比 B 高 5 个点」在 n=20 上可能毫无
意义**。三个实用纪律：对比实验至少报告样本量；小集上「持平」
比「略优」更诚实的结论；要分辨 2–3 个点的差异，n 要上百（或用
配对检验降方差）。展开见 agent-book ch.7。

**三种假绿**（评测自己会骗人的三形态）：

| 假绿 | 形态 | 现形实验 |
|---|---|---|
| 模式方差 | 评测悄悄走了带方差的路径（auto 选到 LLM/不同档位），回归对不上基线 | 锁定确定性模式（规则模式）跑对照——基线必须可复现 |
| 记忆虚高 | 反复跑同批题，记忆把上轮答案记住——检索指标测的是命中不是检索（第 12 章）| 评测默认隔离记忆；对照实验显式开闸 |
| 门槛缺位 | 指标掉了 CI 依然全绿——评测恒成功退出，是仪表盘不是防线 | 门槛通电实验（13.3）——仪表盘不会在深夜叫醒任何人 |

## 13.2 知识：真值集设计、CI 化与评测 harness 四件套

**真值集四要素**：

1. **真值纪律**：期望值人工核对到精确位（多源交叉验证——财报
   数字与次年报表的上期数互核），不是「大概对」——**真值错一题，
   整条防线错位**（你在给系统的错误打分）；
2. **陷阱题**（expect_refused）：应拒答的问题——期间外（2030 年）、
   域外（天气）、语义陷阱（「预计…多少」不是趋势）——**拒答
   正确率是一等指标**（SQuAD 2.0 学统，第 1 章）；
3. **反向断言**（forbid_keywords）：答案**不得**出现已知错误值
   ——问扣非的答案不得含归母的数（第 7 章口径防线的评测面：
   防守知识共享给评测，每次 CI 都跑）；
4. **N/A 的诚实**：无陷阱题的数据集拒答指标记「不适用」不记 0
   ——「不适用」和「零分」是两回事（0 分会被未来的 CI 门槛误判）。

**CI 化**：评测进 CI 要过三关——**确定性**（同口径同模式，基线
可复现，防假绿一）；**门槛**（`--min-*` 低于阈值非零退出——eval
从仪表盘变防线）；**指名道姓**（失败时列出失败题与原因，可定位
而不是一个红叉）。线上另有漂移监控三件：问句日志抽样回放进
评测、verdict 分布看趋势（degraded 占比升高 = 生成/检索在退化）、
浪费率看趋势（agent 环在变懒或变笨）——附录 G 收生产侧。

**评测 harness 四件套**（任何评测系统的骨架）：

| harness | 领域 | 四件套实例 |
|---|---|---|
| [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness) | 基础模型基准 | 数百 task 注册表 / 模型后端统一接口 / per-task 指标 / 版本钉死可复跑 |
| [HELM](https://crfm.stanford.edu/helm/) | 全维评测 | 场景（任务×分布）/ 适配器 / 多维指标（准确性/校准/鲁棒/公平…）/ 排行榜可复现 |
| [SWE-bench](https://arxiv.org/abs/2310.06770) | 真实仓库修复 | 真实 issue+PR / agent 输出→测试执行 / 通过率 / docker 锁环境 |
| 你的评测 | 领域 RAG | 真值集 / 图后端可切换 / 指标+门槛 / CI 同口径复跑 |

**任务集 + 适配器 + 指标 + 可复跑**。先有任务集（你的领域问题），
被测系统经适配器接入（双脑 = 适配器可切换的实例），指标名实
相符，一切为了可复跑（CI 同口径 = 评测自己的评测）。你的毕业
设计交的就是这四件（第 14 章）。

## 13.3 案例研究：Tally 的 evalx 与 judge 演进史

!!! note "案例研究：Tally（evalx.py / cli.py）"

    **七数据集 84 题**（default 10 / innolight 31 / maotai 9 /
    agent 8 / multihop 8 / quarters 8 / multiturn 10 轮），全部
    人工对库核对；七指标：retrieval@3 / answer_hit / refusal /
    citation_coverage / chunk P/R@8 / steps（浪费率）。指标**名实
    相符**改过一次名：faithfulness → citation_coverage——它测引用
    对账不测语义忠实（名字吹的牛会被 RAGAS 用户一眼拆穿）。

    **judge 演进史（量尺也会说谎的三轮）**——关键词判定的子串
    陷阱教科书：

    ```python
    # tally/evalx.py: _kw_in（v3 现行——只守左边界）
    if re.search(r"\d", kw):
        return re.search(rf"(?<!\d){re.escape(kw)}", answer) is not None
    return kw in answer
    ```

    - **v1 OR 子串**：关键词「3.6」子串命中答案里的 13.68/3.68/
      页码日期——分数虚高，**评测在说谎**；
    - **v2 左右都禁数字粘连**：innolight 掉到 **0.963，门槛当场
      红**——定位：真值「51.7」对答案「51.71 亿元」，数据集约定
      是**前缀截断**（38,239 对 38,239,935,640），右边界一禁误杀
      过半真值；
    - **v3 只守左边界**：假命中实测全在左侧粘连（3.6 撞 13.68、
      36,000 撞 136,000），右侧延续恰是截断约定。

    教学价值超过规则本身：**没有门槛，你连自己的量尺坏了都不
    知道**——v2 的误杀若无门槛只表现为「指标莫名掉了」，大概率
    被当成系统回归去查检索层。**量尺 bug 和系统 bug 只有门槛能
    区分**。

    **门槛通电**（`gate_failures` 纯函数 + `sys.exit(1)`，CI 四处
    eval 全挂 1.0 门槛）：通电当天抓到一次真实回归（0.963 那次）。
    坑一枚：期望关键词是 OR 备选组——只改坏其中一个其余照样命中，
    门槛纹丝不动；要触发必须报废整组。LLM 裁判只在 trend 叙述层
    且非对称信任（第 7 章）。

```bash
bash experiments/ch13-gate-trip.sh
# 实测输出（2026-10-22）：
#   exit=1（预期 1）
#   ✗ eval 门槛未过（dataset=default）：answer_hit=0.875 < 1.0
#     ✗ 欧科亿 2026 年半年度预计净利润多少  top1=欧科亿_2026H1E
#       kw=N doc=Y refused=N
#   还原后 exit=0 OK        ← 指名道姓 + 可定位 + 可复现
```

!!! example "毕业练习 ①：为你的语料写 20 题真值集"

    配比：12 单跳（含 4 口径题）+ 4 陷阱（2 期间外 + 1 域外 +
    1 语义）+ 2 对比 + 2 趋势。每题四字段：q / expect_keywords
    （人工对到分位，多源交叉验证）/ forbid（至少 4 题配）/
    expect_refused（陷阱题）。统计纪律：n=20 只够看量级（±13 个
    点的置信区间）——报告里写样本量。这就是你的 harness 四件套
    第一件。

## 13.5 小结

- 三代方法各有所长：无参考评估便宜可规模化但带方差与领域盲区；
  领域真值集贵但是唯一能抓口径混淆这类错的尺子；
- 真值集四要素：真值纪律/陷阱题/反向断言/N-A 诚实；CI 化三关：
  确定性/门槛/指名道姓；线上漂移三件：抽样回放/verdict 趋势/
  浪费率趋势；
- 小样本统计：n=20 一题=5 个点、置信区间 ±13 点——对比结论
  必须报样本量，「持平」常比「略优」诚实；
- 量尺会自己说谎（judge 三轮演进）——量尺 bug 与系统 bug 只有
  门槛能区分；评测 harness 四件套：任务集+适配器+指标+可复跑；
- eval 驱动开发：先有失败样本再写修复。

## 常见误区

**误区一：「有了 RAGAS 就不用自建」。**通用 faithfulness 看不出
「扣非答归母」。框架是补充不是替代——尤其你的口径家族（第 7 章）
只有自己的 forbid 能抓。

**误区二：「LLM-as-judge 更先进」。**judge 是另一个 LLM：有分布、
有盲区、有三类系统偏差。评测层的可复现性比先进性重要——judge
只配坐刹车位。

**误区三：「评测集建完就完了」。**活资产：每次事故入一题、语料
扩容抽验旧题（真值也可能过期）；线上另有漂移监控——离线满分 ≠
线上正确。

**误区四：「指标涨了 2 个点，新方案更好」。**先问 n 和方差。
小集上的 2 个点大概率是噪声——配对检验或加样本量再下结论。
