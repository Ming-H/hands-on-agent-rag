## 8.1 失败先行：两种灾难形态

把 `tally/answer.py` 的 `COVERAGE_THRESHOLD = 0.45` 调成两个极端各跑
一遍真值集：

```bash
# 极端 A：0.0——什么都放行
#   citation_coverage 虚高，口径题答错数字仍 pass——闸门死了，第 9 章灾难全回来
# 极端 B：1.0——近乎全降级
#   大量答案降级抽取式（变丑但全对）、部分被拒——正确性保住，可用性掉一半
```

0.45 不是玄学，是实测分布：合格答案聚在 0.5–0.95，编造答案聚在
0.2 以下——0.45 在两峰之间的谷。**阈值是工程：由数据分布决定，
由回归测试锁定。**

## 8.2 业界视角：可验证 RAG 的三条路线

!!! note "背景速览"

    「怎么保证生成不编」是 RAG 研究的热点，三条代表路线：

    | 路线 | 代表 | 机制 | 代价 |
    |---|---|---|---|
    | 自反思 | [Self-RAG](https://arxiv.org/abs/2310.11511) | 模型生成反思 token 自评检索/生成质量 | 要微调；自己评自己 |
    | 纠错环 | [CRAG](https://arxiv.org/abs/2401.15884) | 检索评估器打分，差则重检/上网补 | 开放世界假设 |
    | **事后归因闸** | Tally / AIS 工程化 | 生成后逐句对账证据池，不过则降级/拒答 | 独立验证器（本文）|

    Tally 选第三条的深层理由：**验证器不能和生成器是同一个大脑**——
    Self-RAG 让模型自评，等于让学生自己批自己的卷子；事后闸用
    确定性代码算覆盖率，与模型能力无关（0.8b 也好 100b 也好，
    闸门同一把尺子）。而 CRAG 的「上网补」违反封闭世界契约——
    金融场景里，检索不到正确口径时**降级到原文**比补一个语义相近
    的网页安全得多。

    评测侧对应物：[RAGAS](https://docs.ragas.io) 的 faithfulness 把
    答案拆成 claims 逐条问 NLI 模型「证据是否蕴含」——语义级但依赖
    裁判模型；Tally 的 `citation_coverage` 是 token 重叠——可计算、
    零依赖但更粗。**知道自己的指标在谱系里的位置，比指标的绝对值
    重要**（所以它从 `faithfulness` 改名，见 8.4）。

## 8.3 三态出口：pass / degraded / refused

verify_citations 是全图唯一出口，任何路径——heuristic 检索、Agent
自主检索、记忆命中、差分派生——都必须过它：

```python
# tally/graph.py: verify_citations（骨架节选）
    verdict, cov = ans.verify(a, pool)          # 引用覆盖率对账
    if verdict == "pass" and not _derived_ok(state.get("derived"), pool):
        verdict = "degraded"                     # 派生值出口重算 ±0.01
    ...
    else:  # degraded：LLM 答案对不上账 → 降级为抽取式（永远有真凭实据）
        body, cited = ans.extractive_answer(state, state["hits"])
```

| 出口 | 含义 | 用户看到 |
|---|---|---|
| pass | 覆盖率 ≥ 阈值 | LLM 组织的完整回答 |
| degraded | 对不上账 | **从证据池抽的原句**（丑但真）|
| refused | 无证据可用 | 拒答 + 现有期间提示 |

degraded 的关键设计：**降级不是重试**——不把答案打回模型改写
（小模型会把同一件事编得更圆），直接换抽取式：每句带引用、每个
数字来自原文。**可靠性由结构保证，不靠模型自觉。**

## 8.4 覆盖率怎么算（以及它不算什么）

- 证据池 = 答案里实际被引用的块 + hits（页窗口自动扩展整页）；
- **只考核数字句**——框架句（「根据提供的证据…」）不要求重叠；
- 两侧 token 剔除元词（公司名/年份/期间）——「欧科亿 2026 年」
  不构成证据相关性；
- 数字归一化注释计入证据（LLM 常答「6.44亿」而非原文全数字）。

**它不算什么**：不保证「答案说的是问的那件事」——问扣非答归母，
只要归母句真在证据池，verify 照样 pass。这道缝隙由第 9 章口径守卫
补，补不完的写进边界账本（第 13 章）。指标名也由此改过一次：
`faithfulness → citation_coverage`——它测的是引用对账，不是语义
忠实度（那个名字会被 RAGAS 用户一眼拆穿）。
