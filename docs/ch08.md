## 本章目标

全书的中心思想落地：答案凭什么出门

## 知识点地图

三态出口（pass/degraded/refused）；引用覆盖率计算与 0.45 阈值；降级链（degraded→extractive→refuse）；LLM 无据→抽取式不拒答；verify 从不豁免任何路径

## Tally 代码锚点

```
tally/graph.py: verify_citations · tally/answer.py: verify / citation_coverage / extractive_answer（COVERAGE_THRESHOLD）
```

## 五段式内容大纲

1. 失败先行：verify=0.4x 的「半对答案」——覆盖率分数的语义边界
2. 覆盖率怎么算：数字句 token 与被引块重叠；为什么 0.45（实测分布）
3. 三态出口设计：宁可降级不可编造——降级后答案=纯抽取证据句（永远真凭实据）
4. 「验证不豁免」：Agent 自主检索/记忆命中/派生值全部过同一道闸

## 破坏性实验

★ 灵魂实验：COVERAGE_THRESHOLD 调 0.0（什么都放行）/ 1.0（大量降级）两极端跑 eval，观察两种灾难形态——阈值是工程不是玄学
