# 第 6 章 查询理解与路由：LLM 当大脑、规则当防线

> 状态：v0.2 · 所属：第二部 求证闸门 · 前置：第 5 章

## 6.1 失败先行：0.8b 的三宗罪

本地小模型驱动查询理解的实测事故（每条都有测试锚定）：

1. **漏抽公司**：compare 题抽对第一家、漏掉第二家——多跳对比退化
   成单公司问答（「哪家题」实测）；
2. **意图漂移**：趋势问句判成 summary；同一 query 三次返回三种意图；
3. **期间幻觉**：问「半年度」抽成 FY——错误参数覆盖后年报块洪水。

结论不是「换大模型」，而是：**LLM 的输出是建议，不是命令。**

## 6.2 业界视角：查询改写与路由的谱系

!!! note "背景速览"

    检索前的查询处理，业界统称 query transformation（
    [LangChain 汇总](https://python.langchain.com/docs/concepts/#query-transformation)）：

    | 技术 | 思路 | 典型场景 |
    |---|---|---|
    | 同义/术语扩展 | 问法→文档术语 | 领域黑话（营收→营业收入）|
    | Multi-Query | LLM 生成多视角查询并行检索 | 召回覆盖 |
    | HyDE | 生成假设答案再检索 | 零词面重叠 |
    | 分解（Decomposition） | 多跳问题拆子问题 | compare/跨年 |
    | 路由（Routing） | 意图分类→不同管线/索引 | 混合工作流 |

    Anthropic 把「路由」列为最基础的工作流模式之一（
    [Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents)）：
    LLM 分类，确定性代码分发。Tally 的 understand 节点是这个模式的
    完整实现，外加一层大多数教程没写的部分——**对分类器本身的不信任**：
    小模型分类会抖动，规则守卫负责把抖动压回语义正确的轨道。

## 6.3 架构：understand 一次结构化抽取 + 八条守卫

LLM 只做一件事：把问题抽成 `{intent, companies, period}`。然后规则
守卫逐条复核（`tally/graph.py: understand`，注释即事故存档）：

```python
# 趋势守卫：小模型实测把趋势问句判成 summary（单文档残渣）
if u.get("intent") == "summary" and _wants_trend(q):
    u["intent"] = "trend"
# 公司漏检守卫：规则的子串匹配是确定性的，LLM 漏抽一家
# 会让 compare 退化成单公司 metric（samples 实测哪家题）
if len(rule_u["companies"]) > len(u.get("companies") or []):
    u["companies"] = rule_u["companies"]
# period 覆盖：query 有明确期间词时规则是确定性子串匹配，
# LLM 抽取实测会稳定抽错（「第一季度」→H1）——规则非空即覆盖
if rule_u["period"]:
    u["period"] = rule_u["period"]
# 对称升级（差分信号）：「第二/四季度」规则层判 trend（差分要走
# 确定性遍历+derive），小模型判 metric 进 agent 环——模型自己差不出
# Q4=FY−Q3，quarters 集 6 道派生题全灭的根因
if u.get("intent") == "metric" and rule_u["intent"] == "trend":
    u["intent"] = "trend"
```

八条守卫全文请读源码——**每条守卫上面写着它防的那次实测事故**，
这是仓库最值得精读的 50 行。设计原则只有一条：**规则是确定性的
地方，规则赢**（公司名子串、期间词表、趋势词表）；语义判断和
隐式期间留给模型。「LLM 提议、确定性裁决」——与 Anthropic 的
工作流哲学同向。

## 6.4 期间守卫：年份不靠模型

```python
# tally/graph.py: route（节选）
q_years = query_years(q)          # 含「15年」→2015 口语年份
have_years = {d.period[:4] for d in corpus.docs.values() if d.period[:4].isdigit()}
if q_years and not (q_years & have_years):
    return {**state, "answer": f"库里没有 {…} 年期间的报告（现有期间：{…}）。"
            f"对不上账，不硬答。", "verdict": "refused", ...}
```

年份来自**文档元数据**（第 2 章文件名契约的下游红利）。确定性
元数据 → 确定性守卫，层的红利会延迟兑现，但一定兑现。
