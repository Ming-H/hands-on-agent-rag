## 本章目标

没有评测的 RAG 是玄学；评测不设门槛的 CI 是装饰

## 知识点地图

真值纪律（人工核对到分位）；七数据集结构（事实/趋势/陷阱/鲁棒/多跳/多轮/差分）；judge 语义（数字左边界/forbid）；retrieval/answer/refusal/citation_coverage/chunk P-R/waste_rate 六指标；--min-* 门槛与 CI 防退化

## Tally 代码锚点

```
tally/evalx.py: judge / summarize / gate_failures · evals/*.json · .github/workflows/ci.yml · docs/RAG-EVAL-CASES.md
```

## 五段式内容大纲

1. 失败先行：eval 恒 exit 0 的装饰性 CI——指标跌到 0.3 也全绿（本项目真实踩过）
2. judge 演进史：OR 子串的假命中 → 数字左边界（51.7→51.71 前缀截断约定 vs 3.6→13.68 假命中）→ forbid 反向断言
3. 指标诚实：citation_coverage 改名史（faithfulness 名不副实）；refusal 对无陷阱集记 N/A 的原因
4. 门槛通电：--min-* 低于即非零退出，CI 从「只防崩溃」到「防退化」
