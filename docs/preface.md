# 前言：为什么写这本书

## 一句话

市面上教「怎么把 RAG 跑起来」的教程已经太多；这本书教的是
**「怎么让 RAG 不敢编造」**——以一个真实开源项目
（[Tally](https://github.com/Ming-H/tally)）为唯一实验室，从 PDF
语料一路走到 Agent 四支柱与评测体系，并把每一步的决策方法变成
你可以搬到自己语料上的东西。

## 本书的来历

Tally 不是为教学准备的玩具：它是一个人在 2026 年 10 月里、踩着
26 个实测决策（D1–D26）、3 次事故复盘和 40 道人工核对真值题长出来的
财报问答系统。本书做的事是给这个「结果」补一条「过程」的缓坡。
**失败先行**不是教学技巧，是这个项目真实的成长方式——每章先让你
看一次失败（很多章第一个实验就是亲手把它拆坏），再讲为什么这样修。

## 怎么读

| 你是谁 | 路径 |
|---|---|
| 按部就班 | ch1→ch14 顺序读，每章实验跟着做 |
| 做过 RAG、补 Agent 面 | 第四部分（ch8–12）直奔主题，回头补第三部分 |
| 面试冲刺 | 快线 ch1 / ch5 / ch7 / ch11 / ch14 + 附录 D 决策索引 |

教学序 ≠ 运行序：第三部分（生成/验证）先于第四部分（理解/路由）
讲——因为 ch6–7 全程可用规则脑（`--mode heuristic`）零 key 跑通，
ch8 才接 LLM。规则脑不是降级兜底，是教学脚手架。

体例说明（每章三栏 + 盒子）：

- **知识点**：业界谱系与方法（每章开篇正文，带一手出处）；
- **本项目**：Tally 代码锚定走读（`文件名 + 函数名` 锚定，完整代码
  以 Tally 仓库为准，**锁定 v0.7+ tag**——代码会演进，本书引用以
  函数名为锚）；
- **动手**：破坏性实验（命令 + 预期输出 + 指标变化）+ 分级练习
  （★ 读写题 / ★★★ 带骨架的实现题，骨架在教程仓 `exercises/`）；
- 可选件：**迁移盒**（换语料三问：语料差异 → 哪个决策变 → 对应
  哪个机制）、**失败卡**（提示注入这类横切风险）、重点章的
  **前沿拓展**完整节（ch05/07/11/12/14）；
- **D 编号**（D1–D26）：Tally 设计文档的决策记录编号，正文引用处
  可溯源到 `docs/DESIGN-*.md` 原文。

四个里程碑：ch05 语料可检索 → ch07 可信固定管线 RAG → ch12 Agent
完全体 → ch14 能证明、能迁移。毕业设计 = 附录 F 设计画布填满 +
20 题真值集 + 跑出三态出口。

## 诚实边界

- 本书全部实测数字来自 Tally v0.7（2026-10）；标 ★ 的实验在作者机
  验证过，其余按脚本可复现（`experiments/`）；
- Tally 有它管不住的问题（ch14 边界账本）——本书不装完美；
- Anthropic 兼容通道的 ReAct 工具环尚未接通（ch11 详述，OpenAI
  兼容远端 v0.7.1 已接）——这是留给读者的 v1.1 挑战，不是被藏
  起来的缺陷。

祝你拆得开心。
