# 前言：为什么写这本书

## 一句话

市面上教「怎么把 RAG 跑起来」的教程已经太多；这本书教的是
**「怎么让 RAG 不敢编造」**——一本自足的 Agentic RAG 工程教程：
知识体系完整，可脱离任何代码仓库阅读；开源项目
[Tally](https://github.com/Ming-H/tally)（中文财报事实 Agent）作为
**贯穿全书的案例研究**穿插各章，动手实验也在它上面做。

## 本书的写法

每章固定四段：**X.1 问题与原理**（领域无关的深度讲解：失败
模式与机理、技术谱系与代表系统**机制**、一手论文的实测数字、
可迁移的设计原则与决策框架——不读案例也完整）；**X.2 案例研究**
（Tally 在这个问题上的设计取舍、关键代码段走读、实测数字与业界
分歧，统一冠名、可整节跳过）；**X.3 动手**（破坏性实验 + 脱离
案例的迁移练习，含带骨架的实现题）；收尾（小结/**设计清单**/误区/延伸阅读）。多数
知识节配「演练」——带数字的逐步推演（四代同题之旅、AIS 判定、
judge 三版对撞、eₖ·gₖ 账本、成本账单）。

这个写法向前辈取了经：Chip Huyen《AI Engineering》的知识自足与
案例佐证（[aie-book](https://github.com/chiphuyen/aie-book)）、
李博杰《深入理解 AI Agent》的一章一域加配套实验
（[ai-agent-book](https://github.com/bojieli/ai-agent-book)）。与前两者的
差别在载体：本书每章的案例研究落在**同一个**真实项目上——你在
第 2 章读过的文件名契约，到第 14 章的总装走读里还会再出现一次。

## 怎么读

| 你是谁 | 路径 |
|---|---|
| 按部就班 | ch1→ch14 顺序读，每章实验跟着做 |
| 做过 RAG、补 Agent 面 | 第四部分（ch8–12）直奔主题，回头补第三部分 |
| 面试冲刺 | 快线 ch1 / ch5 / ch7 / ch11 / ch14 + 附录 D 决策索引 |

教学序 ≠ 运行序：生成/验证（ch6–7）先于理解/路由（ch9）讲——
因为前者全程可用规则脑（`--mode heuristic`）零 key 跑通，第 8
章才接 LLM。四个里程碑沿途立桩：ch05 语料可检索 → ch07 可信
固定管线 → ch12 Agent 完全体 → ch14 能证明、能迁移。毕业设计 =
附录 F 设计画布填满 + 20 题真值集 + 跑出三态出口。

## 诚实边界

- 案例实测数字来自 Tally v0.7（2026-10），实验按脚本可复现
  （`experiments/`）；
- 案例有它管不住的问题（ch14 边界账本）——本书不装完美；
- Anthropic 兼容通道的工具环尚未接通（ch11）——留给读者的
  v1.1 挑战，不是被藏起来的缺陷。

祝你拆得开心。
